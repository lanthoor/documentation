Understand spending behavior with timeline views, category distribution, and trend charts.

## Key capabilities

- View dashboard summaries by month and year
- Switch between calendar year and financial year
- Analyze category breakdown with interactive pie chart
- Track trends using interactive line chart
- Review recent transactions for quick context

## Typical flow

1. Open analytics from the main navigation.
2. Choose time period and year mode.
3. Inspect chart segments and trend points for details.
4. Cross-check with transaction list and category filters.

- Current exports focus on JSON backups; PDF and CSV reporting are planned.
