Organize transactions with a unified category model shared across expenses and income.

## Key capabilities

- Use predefined categories across all transaction types
- Maintain consistent grouping for analytics and budgets
- Customize category visuals with icon and color
- Reassign entries before deleting a category

## Typical flow

1. Review or create categories from settings.
2. Assign categories while adding transactions.
3. Use categories to filter lists and analytics views.
4. Reassign transactions when category cleanup is needed.

## Notes

- Spendly uses a unified category system rather than separate income and expense sets.
