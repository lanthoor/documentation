Protect financial data with on-device app lock and lifecycle-aware access controls.

## Key capabilities

- Enable biometric app lock (fingerprint or face unlock)
- Configure lock timeout windows
- Re-lock app based on background duration
- Use full-screen lock overlay with biometric prompt

## Typical flow

1. Open settings and enable app lock.
2. Set preferred timeout policy.
3. Move app to background and return after timeout.
4. Authenticate with biometrics to resume access.

## Notes

- Security controls are designed for local, offline usage.
