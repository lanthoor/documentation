Use a streamlined Android interface with adaptive navigation and focused finance workflows.

## Key capabilities

- Navigate with Home, Transactions, Analytics, and Settings tabs
- Access dashboard widgets and recent activity quickly
- Use search and filters for date, category, and account
- Create and edit entries in modal bottom sheets
- Choose light, dark, or system theme behavior

## Typical flow

1. Start on Home for monthly summary and recent transactions.
2. Move to Transactions for detailed history and filters.
3. Open Analytics for charts and trend exploration.
4. Use Settings for preferences and account/category management.

## Notes

- Layout adapts across phone and tablet form factors.
