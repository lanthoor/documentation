Track daily spending with detailed entries, optional categories, account mapping, and receipt attachments.

## Key capabilities

- Add, edit, and delete expense entries
- Save amount with paise precision
- Assign category, account, date, and description
- Configure recurring expenses (daily, weekly, monthly)
- Attach receipt files (JPG, PNG, WebP, PDF)
- Auto-detect eligible expense SMS messages

## Typical flow

1. Open the add transaction flow from the main screen.
2. Enter amount and choose account and category.
3. Add optional notes and attach receipt files.
4. Save the transaction and review it in the latest-first list.

## Notes

- Default account is `My Account`.
- Default category fallback is `Others` when not selected.
